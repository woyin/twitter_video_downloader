# iOS 快捷指令:X/Twitter 视频一键存相册

把 `x.com` / `twitter.com` 视频推文,**一键解析直链并存进 iPhone 相册**。
调用你部署在 `https://td.woyin.me` 的解析服务(`/extract` 接口)。

---

## 方式一:直接导入 `.shortcut`(先试这个)

仓库 `shortcut/` 目录下有生成好的 `X视频下载.shortcut`。

1. **先开「允许不受信任的快捷指令」**(必做,否则导入报错):
   `设置 → 快捷指令 → 打开「允许不受信任的快捷指令」`(会让你重启设备/设密码)。
2. 把 `X视频下载.shortcut` 传到 iPhone(AirDrop / 邮件 / iCloud Drive / 自己建个静态下载链接均可)。
3. 在文件里点开 → **「添加快捷指令」**。
4. 导入时它会**弹窗问你 API Key**——填入你 `docker-compose` 里那个 `API_KEY` 的值。
5. 进去把第 1 个「文本」动作里的占位符也确认改成同一个 key(导入问题没填上的话)。

> ⚠️ 这个文件是**尽力生成(best-effort)**的二进制。`.shortcut` 里个别动作的参数键若与现代 iOS 略有出入,**导入后某个动作可能显示为空白/红色**。若如此,删掉那一个动作,按下方「方式二」用同名动作补上即可。其余照常。

---

## 方式二:手搓(保底,4 分钟,100% 可靠)

打开「快捷指令」App → 新建快捷指令 → **依次添加以下动作**(括号里是该动作要填/选的值):

| # | 动作 | 设置 |
|---|------|------|
| 1 | **文本** | 内容先随便填,待会替换成你的 `API_KEY`(纯文本) |
| 2 | **设定变量** | 变量名填 `api_key`;值 = 上一个「文本」的结果(直接连上即可) |
| 3 | **获取变量** | 选 `快捷指令输入`(Shortcut Input) |
| 4 | **要求输入** | 类型选 `URL`;提示语 `粘贴 x.com / twitter.com 视频链接`;**默认答案** = 第 3 步的结果 |
| 5 | **URL 编码** | 输入 = 第 4 步结果;编码方式选 `URL`(或 `URL 组件`) |
| 6 | **文本** | 内容拼成(把两个变量拖进去):`https://td.woyin.me/extract?xid=`〈第5步结果〉`&x-api-key=`〈第1步文本〉 |
| 7 | **获取 URL 内容** | URL = 第 6 步结果;方法 `GET`;展开「头」加一行 `Accept` = `application/json`(可选) |
| 8 | **获取词典值** | 获取 = `词典中的值`;键 `video_url`;输入 = 第 7 步结果 |
| 9 | **获取词典值** | 键 `message`(失败原因,留着备用);输入 = 第 7 步结果 |
| 10 | **获取 URL 内容** | URL = 第 8 步的 `video_url`;方法 `GET`(这一步就是下载 mp4) |
| 11 | **存储到照片图库** | 相册默认即可;输入 = 第 10 步结果 |
| 12 | **显示结果** | 内容 `✅ 已保存到相册` |

> 说明:这套**没有用「如果」分支**(If 在二进制里最易出错,所以生成版也没用)。
> 推文**有视频**时一路跑到底、存进相册;**无视频**时第 10 步因 `video_url` 为空会报错停下——
> 这就是「没视频」的反馈。想要更优雅的失败提示,见下「可选增强」。

### 启用「分享菜单」触发(一键)
快捷指令详情页(右上 ⓘ):
- **「在共享表单中显示」** → 打开;
- **「接受的内容」** 只勾 `URL`、`网页`(Safari)、`文本`。
之后在 X App / Safari 看到视频推文 → 分享 → 选本快捷指令 → (链接已预填)点「完成」→ 自动解析+存相册。

---

## 可选增强:优雅的失败提示(加 If)

在第 8 步拿到 `video_url` 后,加:
- **如果** `video_url` **有任何值** → 走第 10~12 步(下载+存相册);
- **否则** → **显示结果** `❌ 失败:`〈第 9 步 message〉。

（`获取词典值` 拿不到值时为空,正好触发「否则」分支。)

---

## 测试

1. 确认服务器已部署且 `API_KEY` 已设、`docker compose` 已重启。
2. 在 iPhone Safari 打开一个有视频的推文(如随便找个 `x.com/.../status/...`)。
3. 分享 → 选本快捷指令 → 看相册是否多了一段视频。
4. 若失败,在服务器看日志:`docker logs -f twitter_video_downloader`,常见是 403(key 不一致)或解析超时。

## 安全提醒
- 这个 `.shortcut` 里**硬编码了你的 API Key**——**不要把它分享给别人**,否则等于把服务器密钥送人。
- 想公开分享快捷指令给别人,得改成「无鉴权 + 服务器加 IP 限流」的方案(本仓库没做,需要再聊)。
